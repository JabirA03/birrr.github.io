Web Application

MindBodyHealth

MindBodyHealth merupakan aplikasi berbasis web yang dirancang untuk membantu pengguna memantau kondisi kesehatan mental dan fisik melalui berbagai fitur interaktif seperti self assessment, monitoring aktivitas, informasi kesehatan, serta rekomendasi gaya hidup sehat secara digital.

Role

Web Developer

Duration

Academic Project

Status

Completed

Project Overview

MindBodyHealth dikembangkan sebagai website pelayanan kesehatan yang mengintegrasikan pemantauan kondisi mental dan fisik dalam satu platform. Melalui website ini, pengguna dapat melakukan evaluasi mandiri (self assessment), memantau perkembangan kondisi kesehatan, memperoleh edukasi gaya hidup sehat, serta mengatur pengingat rutinitas harian secara fleksibel dari berbagai perangkat.

Technology Stack

Laravel & PHP

Backend Framework

MySQL

Database

Bootstrap

CSS Framework

Development Process

1. Requirement Analysis

Mengidentifikasi kebutuhan sistem dan menyusun instrumen kuisioner digital untuk pemantauan indikator kesehatan mental serta fisik.

2. UI/UX Design

Mendesain antarmuka web yang intuitif, menenangkan, dan responsif agar nyaman diakses baik melalui layar laptop maupun browser smartphone.

3. System Development

Membangun arsitektur website menggunakan Laravel, Bootstrap untuk tata letak antarmuka, serta MySQL untuk penyimpanan data evaluasi dan riwayat kesehatan.

4. Testing & Deployment

Melakukan pengujian fungsionalitas antarmuka, verifikasi perhitungan kuisioner, serta optimasi performa sebelum platform dipublikasikan.

Results & Conclusion

Website MindBodyHealth berhasil menghadirkan platform edukasi dan pemantauan kesehatan mental serta fisik secara terpadu. Tampilan web yang responsif memberikan pengalaman pengguna yang nyaman dalam melacak kondisi kesehatan dan membangun pola hidup yang lebih seimbang.
